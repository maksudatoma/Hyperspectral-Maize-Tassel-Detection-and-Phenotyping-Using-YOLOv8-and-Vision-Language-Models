# Hyperspectral-Maize-Tassel-Detection-and-Phenotyping-Using-YOLOv8-and-Vision-Language-Models
## Maize Tassel Detection Using Hyperspectral Imaging  This project develops a deep learning pipeline for automated maize tassel detection and phenotype extraction using hyperspectral imaging data. The workflow includes spectral band analysis across 243 bands, calibrated single-band image export, Roboflow annotation, and YOLOv8 training.
